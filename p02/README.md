# Deklarasi AI

**Label AI 1**
* **Alat yang dipakai:** AI Gemini.
* **Untuk apa:** AI digunakan sebagai pendamping (asisten) untuk membantu memastikan pemilihan tipe data (string vs int/double) sudah tepat sesuai modul, dan untuk memberikan contoh sintaks penyelesaian TODO pada program `sinilai_v01.cpp` agar terhindar dari pesan *error*.
* **Cara memeriksa:** Saya telah meninjau kode yang dihasilkan, memastikan nama variabel mengikuti kesepakatan kelas (huruf kecil), membangun (build) kode tersebut secara lokal melalui Git Bash menggunakan parameter kompilasi `-Wall -Wextra -Wpedantic`, serta memvalidasi hasil keluarannya (output) dengan teknik redirection menggunakan file `contoh_masukan.txt` sehingga hasilnya benar-benar sesuai dengan spesifikasi yang diminta modul.
